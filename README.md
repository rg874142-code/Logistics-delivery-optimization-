# Logistics Delivery and Inventory Optimization Using Data Science

## Overview
This project analyzes logistics delivery and inventory data using Python and data science techniques.

## Objectives
- Analyze delivery performance
- Calculate logistics KPIs
- Identify delivery delays
- Analyze transportation costs
- Compare inventory and demand
- Create useful visualizations

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Scikit-learn

## KPIs
1. On-Time Delivery Rate
2. Average Delivery Cost
3. Average Delivery Distance
4. Inventory vs Demand Analysis

## Project Structure

- `logistics_data.csv` - Logistics dataset
- `logistics_analysis.py` - Python analysis code
- `requirements.txt` - Required Python libraries
- `graphs/` - Generated charts
- `notebooks/` - Jupyter Notebook
- `report/` - Project report

## How to Run

```bash
pip install -r requirements.txt
python logistics_analysis.py
